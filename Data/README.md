# Data

The raw dataset (`hotel_bookings.csv`, 119,390 rows x 32 columns, about 16.9 MB) is **not included** in this repository. Confirm redistribution terms on the Kaggle page before adding it.

## How to obtain it
1. Download **Hotel Booking Demand** from Kaggle: https://www.kaggle.com/datasets/jessemostipak/hotel-booking-demand
2. Save it as `data/hotel_bookings.csv` (git-ignored).

## Original source
Antonio, N., de Almeida, A., & Nunes, L. (2019). *Hotel booking demand datasets.* Data in Brief, 22, 41-49.

The file audited in this project had 119,390 rows and 32 columns and was left unmodified.
