Data

The original dataset, "hotel_bookings.csv", contains 119,390 rows and 32 columns (approximately 16.9 MB). The raw dataset is not included in this repository.

How to Obtain the Dataset

1. Download Hotel Booking Demand from Kaggle:
   https://www.kaggle.com/datasets/jessemostipak/hotel-booking-demand
2. Place the downloaded CSV file in the "Data/" directory as "hotel_bookings.csv".

Data Preparation

The original dataset was reviewed, and columns that were not required for the project's analysis were removed. The resulting dataset, named "Final_Data_File", is stored in the same "Data/" folder and serves as the dataset used for the subsequent database development, data modeling, and Power BI dashboard analysis.

Original Source

Antonio, N., de Almeida, A., & Nunes, L. (2019). Hotel booking demand datasets. Data in Brief, 22, 41–49.
